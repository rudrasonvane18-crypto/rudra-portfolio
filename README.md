# Rudra Sonvane — Personal Portfolio

A responsive, premium-dark personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser. No build tools or installation required.

## Personalize before publishing
Search the project files for the following placeholders and replace them:
- `your.email@example.com` — your professional email address.
- `https://www.linkedin.com/` — your LinkedIn profile URL.
- `https://github.com/` — your GitHub profile URL.
- `Add your college/university name` — your actual BCA institution.
- Project cards are sample project concepts marked **CONCEPT**. Replace them with projects you have actually completed, including a short description, tools used, screenshots and GitHub/demo links.
- Review the skills list and remove any tool or technique you have not used yet.

## Publish free with GitHub Pages
1. Create a GitHub repository named `rudra-portfolio`.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. GitHub will provide your public website URL after deployment.

You can also deploy the folder using Vercel or Netlify. The site uses Google Fonts when internet access is available; system fallbacks are included.
